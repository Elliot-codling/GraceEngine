# Documentation Layout

This documentation is organised into several sections:

- **About** contains the introduction as well as information about the engine such as the installation, requirements and history. 
- **Getting Started** contains all the necessary info on how to start your game! We recommend to follow this guide if you are new.
- **Manual** includes feature-specific tutorials and documentation. It may be referenced throughout this documentation as guide for a feature.
- **Class Reference** documents all of GraceEngine API calls, including their expected parameters and outputs.
