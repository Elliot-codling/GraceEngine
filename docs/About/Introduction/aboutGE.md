# Introduction

Welcome to GraceEngine, it is a free and open source project created by Elliot Codling and Co-created with Anthony Hood.
It is a community driven 2D game engine! Powered by SFML, this capable tool can develop your game. We aim to create a user-friendly experience for your project.
We want you to show off what you can do with GraceEngine.


This page provides an introduction about the engine and this documentation so that you know how to get started with your next project.

## About GraceEngine

Don't despair! You may overlook the capabilities of SFMl, but it does have a lot of features 2D games require.
Not only that, it is a well documented library backed with a community ready to help at will. To learn more about SFML you can click [here](https://www.sfml-dev.org/) to be directed to their website.

GraceEngine is a feature rich, cross-platform game engine to create 2D games. It provides a set of well written tools, so that users can focus on creating games rather than starting from scraps.
Games can be created entirely without the UI and instead can write pure code if you wish to do so. We also have our upcoming UI editor that allows you, the user, to focus on the game design rather than starting from a blank canvas.

This tool is completely free under the MIT licence. No royalties, no limitations, nothing. What the user sees is what the user receives, down to the last line of code.
Our aim is to empower users to help shape their engine to match their desires.
