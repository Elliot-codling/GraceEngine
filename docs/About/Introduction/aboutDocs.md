# About this Documentation

Our team are continuously improving on this documentation as well as GraceEngine. We welcome anyone wanting to help contribute to this project, it can be as small as a typo in the documentation or an entirely new feature-set.
You can contribute by opening up [GraceEngine on Github](https://github.com/Grace-Engine-Org/GraceEngine) and reporting issues or feedback to us.
