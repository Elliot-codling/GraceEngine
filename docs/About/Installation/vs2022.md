# Install GraceEngine via VS2022

{: .important}
This page only applies to Windows due to macOS dropping support for VS and Linux having no support for VS.

## VS2022 - MSVC for x86_64 processors

1. Download the project from the Github release page using your preferred method. However, you can clone from the stable branch if you wish to do so.
1. Open up the project via VS2022.
1. By default, the configuration is x64-Debug, you can configure this to x64-Release if you wish to do so.
1. Click the run button.

## VS2022 - MSVC for ARM processors

1. Download the project from the Github release page using your preferred method. However, you can clone from the stable branch if you wish to do so.
1. Open up the project via VS2022.
1. By default, the configuration is arm64-Debug, you can configure this to arm64-Release if you wish to do so.
1. Click the run button.
