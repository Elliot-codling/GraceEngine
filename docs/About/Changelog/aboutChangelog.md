# About Changelog

GraceEngine is continuously being improved and iterated. New features may be added, existing ones modified or older ones deprecated.
To see what is new with each version of GraceEngine you can see it here in the changelog section of the documentation.

GraceEngine version updates go by the following suffix: major.minor.patch
- **Major** updates occur when the engine goes under large changes to features. For example: API calls may change what inputs they receive or outputs may return different results.
- **Minor** updates are when new features are added, existing API calls may be changed internally but fundamentally expect the same. 
- **Patch** changes fix bugs of various severities. Bugs must be patched even if the behaviour is favorable. 

This does not mean the patch number is designated to only bugs. Minor updates may also include bug fixes, and major updates may include new features.
